# RentEase – Online Rental Marketplace

RentEase is a full-stack rental marketplace application that connects Lessors (product owners) and Lessees (renters). Users can register based on their role and perform actions such as listing products, browsing items, adding products to cart, and booking rentals.

## Features

- Role-based authentication and authorization (Admin, Lessor, Lessee)
- Product listing and management for lessors
- Product search and filter by category, brand, and price for lessees
- Shopping cart and checkout functionality with rental duration
- Booking availability checks
- Review and rating system for lessees
- Admin dashboard for managing users and products

## Technologies Used

### Backend
- Java 17
- Spring Boot
- Spring MVC
- Spring Data JPA (Hibernate)
- MySQL
- RESTful APIs

### Frontend
- React.js
- Axios
- React Router
- Bootstrap or Tailwind CSS
